# ステッピングモーターの動作確認

Arduino UnoとULN2003ドライバーボードで、28BYJ-48（5V）を1台動かすサンプルです。

## 配線

電源を切った状態で配線してください。モーターの5ピンコネクターは、ULN2003ボードの対応するソケットに接続します。

| ULN2003の端子 | 接続先 |
| --- | --- |
| IN1 | Arduino A0 |
| IN2 | Arduino A1 |
| IN3 | Arduino A2 |
| IN4 | Arduino A3 |
| ＋ / VCC | 外部の安定化5V電源の＋ |
| − / GND | 外部電源の−とArduinoのGNDの両方 |

Arduino本体はUSBで給電します。モーター用の外部電源は5V・1A程度を目安にし、外部電源の＋はULN2003ボードにだけ接続してください。Arduinoと外部電源のGNDは共通にします。

## 書き込みと動作

1. Arduino IDEで `stepper_single/stepper_single.ino` を開きます。
2. 使用するArduinoのボードと接続ポートを選びます。
3. スケッチを書き込み、モーター用の5V電源を入れます。

`Stepper.h` が見つからない場合は、ライブラリマネージャーでArduino提供の `Stepper` をインストールしてください。

約15回転/分の速度で「約1回転 → 1秒停止 → 逆方向に約1回転 → 1秒停止」を繰り返します。

配線はA0・A1・A2・A3の順ですが、コードのピン指定はコイルの駆動順に合わせてA0・A2・A1・A3の順にしています。D2〜D5を使う場合は、スケッチ内の `Stepper motor(...)` の宣言をコメントアウトされた方に切り替え、配線もIN1〜IN4をD2〜D5に変更してください。
